# 🧠 Psycheflux Oracle Inkblot Simulator

*A Two-Phase Oracle Ritual in p5.js*

> *"The ink of the forest soul."*

An immersive interactive experience where evolving forest-green inkblots transform into personal oracle readings. Built with p5.js, this mystical simulator combines procedural generation, sacred symbolism, and poetic reflection.

## ✨ Features

### Phase 1: The Living Inkblot
- **Evolving organic forms** generated with Perlin noise flow fields
- **Vertical symmetry** creating Rorschach-style inkblots
- **Deep forest green ink** (#013220) with golden-green glow
- **Guardian light orbs** pulsing softly in each corner
- **Click and hold** for 2 seconds to freeze and capture your vision

### Phase 2: Oracle Reflection
- **Symbolic interpretation** of what you see
- **Archetypal readings** for wolf, eye, spiral, doorway, snake, tree, flame
- **Mystical interface** styled with parchment textures and ancient typography
- **Save your visions** as PNG images with timestamps

## 🎨 Visual Style
- Rich forest green evolving inkblots on antique parchment
- Softly glowing golden edges and auras
- Guardian light orbs watching from the corners
- Serif fonts (Cinzel, Playfair Display) for sacred presence

## 🚀 Usage

Simply open `index.html` in a modern web browser.

1. **Observe** the evolving inkblot as it morphs and flows
2. **Hold** your mouse or touch for 2 seconds when you see something meaningful
3. **Reflect** by typing what you see in the vision
4. **Receive** your oracle reading based on archetypal symbols
5. **Save** your vision to keep the moment

## 🛠️ Technical Details

- Built with [p5.js](https://p5js.org/) 1.7.0
- Procedural generation using Perlin noise
- Canvas-based rendering with shadow effects
- Responsive design for all screen sizes
- No backend required - runs entirely client-side
