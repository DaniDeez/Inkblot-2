# 🌈 Inkblot Simulator - Oracle Mirror

A mesmerizing Rorschach-style inkblot generator that creates perfectly symmetrical, animated forms that bloom and flow like mirrored visions from the subconscious. This interactive oracle tool combines art, psychology, and mysticism to create a unique introspective experience.

## ✨ Features

### Visual Experience
- **Symmetrical Inkblots**: Perfectly mirrored shapes that create harmonious, balanced forms
- **Organic Animation**: Smooth, lava lamp-like motion with flowing, pulsing edges
- **Kaleidoscopic Colors**: Continuous transitions through vibrant color palettes
- **Ethereal Glow**: Soft shadows and luminous effects that enhance the mystical atmosphere

### Interactive Elements
- **New Inkblot Button**: Generate fresh evolving forms at any time
- **Click to Freeze**: Capture any moment of the animation to reflect upon
- **Intuitive Input**: Share what you perceive in the frozen inkblot
- **Oracle Readings**: Receive personalized interpretations based on your vision

### Oracle System
- **Color Reading**: Analysis of dominant hues and their emotional/energetic signatures
- **Symbolic Interpretation**: Deep archetypal meanings from a curated oracle dictionary
- **Psychological Reflection**: Insights into your subconscious perceptions

## 🚀 Getting Started

### Quick Start
Simply open `index.html` in any modern web browser. No installation or build process required!

### How to Use

1. **Watch**: Let the inkblot animate and flow, shifting through colors and forms
2. **Freeze**: Click anywhere on the inkblot when a shape speaks to you
3. **Reflect**: A rainbow prompt will appear asking "What do you see?"
4. **Share**: Type what you perceive - a symbol, figure, or impression
5. **Receive**: Get your color reading and symbolic interpretation
6. **Continue**: Click "Continue" to resume the animation, or "New Inkblot" to start fresh
