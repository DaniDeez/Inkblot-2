# 🌀 The Void Mirror

*"Ink as shadow, silence, and unseen truth."*

An interactive Rorschach-style inkblot oracle that merges art, perception, and psychology into a mystical mirror of the subconscious.

## ✨ Features

### Living Inkblots
- **Perfect Symmetry**: Every inkblot is mirrored along the vertical axis, creating classic Rorschach patterns
- **Organic Animation**: Blobs flow and pulse with lava-lamp fluidity at medium speed
- **Dynamic Forms**: Multiple distinct shapes with tendrils, branches, and meaningful negative space
- **Wild Motion**: Endless variations emerge through continuous transformation

### Interactive Oracle
- **Freeze & Capture**: Click anywhere on the inkblot to freeze the animation at that exact moment
- **Vision Prompt**: Share what you see in a gentle, unobtrusive interface
- **Color Reading**: Receive emotional and energetic signatures based on dominant hues
- **Symbolic Interpretation**: Get archetypal insights from a curated oracle dictionary

### Aesthetic
- **Pure Black Ink** (#0a0a0a) on **Antique Parchment** (#f7f1e1)
- **Sepia Undertones**: Subtle texture for an ancestral, timeless feel
- **Glowing Star Orbs**: Faint luminous particles emerge and dissolve at the edges
- **Introspective Mood**: Liminal, contemplative, and mystical

## 🎮 How to Use

1. **Watch**: Let the inkblot bloom and transform before your eyes
2. **Click**: Freeze the animation when a shape speaks to you
3. **Reflect**: Type what you see in the vision prompt
4. **Receive**: Get your color and symbolic reading
5. **Renew**: Click "New Inkblot" to generate a fresh pattern

## 🚀 Getting Started

Simply open `index.html` in any modern web browser. No build process or dependencies required.

```bash
# Clone the repository
git clone https://github.com/DaniDeez/Inkblot-2.git

# Navigate to the directory
cd Inkblot-2

# Open in browser
open index.html  # macOS
xdg-open index.html  # Linux
start index.html  # Windows
```

## 🧠 The Oracle Dictionary

The symbolic interpretation engine includes meanings for:
- Animals & mythical creatures (butterfly, dragon, wolf, owl...)
- Human forms (eyes, hands, face, angel...)
- Natural elements (tree, water, fire, mountain...)
- Abstract symbols (mirror, key, spiral, void...)
- Emotional states and archetypal patterns

Each symbol offers psychological reflection, archetypal resonance, and intuitive guidance.

## 🎨 Technical Details

- **Pure Vanilla JavaScript**: No frameworks, no dependencies
- **HTML5 Canvas**: Dual-layer rendering for inkblots and star effects
- **Perlin-like Noise**: Organic movement algorithms for natural flow
- **Responsive Design**: Works on desktop and mobile devices
- **Color Analysis**: Real-time pixel sampling for dominant hue detection
